# 🚆 RailNexis

## Intelligent Railway Reservation and Delay Prediction System

RailNexis is a full-stack MERN application developed as an MCA Major Project. The system provides railway reservation management, train status tracking, PNR enquiry, occupancy analytics, transaction history, notifications, and AI-based delay prediction.

## Features

* User Authentication using JWT
* Train Search and Ticket Booking
* Multi-passenger Reservation System
* PNR Status Tracking
* Live Train Status Monitoring
* Railway Route Visualization using Leaflet Maps
* Transaction History
* Personalized Notifications
* Occupancy Dashboard
* Analytics and Revenue Reports
* AI-based Delay Prediction
